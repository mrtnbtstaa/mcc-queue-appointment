# mcc_registrar

## Deploy to Vercel

Import this repository into Vercel and add `API_BASE_URL` to the project's
Production environment variables (for example, `https://your-api-host/api/`).
Vercel uses `vercel.json` to build Flutter Web and serve `build/web`; the
build script pins Flutter 3.50.0 and fails if the API URL is missing.
